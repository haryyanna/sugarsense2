# fatsecret Platform API

> fatsecret is a global nutrition and wellness platform. Its Platform API exposes a verified food
> database of more than 1.9 million items across 56+ countries, plus recipes, exercises, barcode
> lookup, AI image recognition and natural-language food parsing, and profile-scoped food diary,
> exercise diary and weight tracking. The provider states the API serves 35,000+ developers and more
> than 700 million calls per month.

Generated by API Evangelist from apis.yml and the artifacts in this repo on 2026-08-12.
fatsecret does not publish an llms.txt of its own — https://platform.fatsecret.com/llms.txt returns
the portal's single-page-app HTML shell (a soft 200, not a document).

## Key facts an agent needs first

- Base URL: https://platform.fatsecret.com/rest
- The default response format is **XML**. Pass `format=json` on every call or you will get XML.
- Versions travel with the METHOD, not the API: `/foods/search/v5`, `/food/v4`, `/recipes/search/v3`,
  `/food-brands/v2`, `/food/barcode/find-by-id/v1` all coexist.
- Errors come back in the BODY as `{"error":{"code":N,"message":"..."}}` — the HTTP status is not the
  signal. Code 11 = application quota exhausted; code 14 = token is missing a required scope.
- There is **no idempotency key**. Retrying a diary write can double-post it.
- There are **no rate-limit response headers**. Basic edition is 5,000 calls/day; you learn you are
  over only from error code 11.

## Authentication

- OAuth 2.0 client_credentials for catalog data: https://platform.fatsecret.com/docs/guides/authentication/oauth2
- 3-legged OAuth 1.0a for member/profile data: https://platform.fatsecret.com/docs/guides/authentication/oauth1/three-legged
- Token endpoint: https://oauth.fatsecret.com/connect/token
- OIDC discovery: https://oauth.fatsecret.com/.well-known/openid-configuration
- Scopes: basic, premier, barcode, localization, nlp, image-recognition, feedback

## APIs

- [Foods API](https://platform.fatsecret.com/platform-api): search, autocomplete, barcode lookup, food detail
- [Recipes API](https://platform.fatsecret.com/platform-api): recipe search, recipe detail, recipe types
- [Reference API](https://platform.fatsecret.com/platform-api): brands, categories, sub-categories, exercises
- [Profile Foods API](https://platform.fatsecret.com/platform-api): favorite foods
- [Profile Meals API](https://platform.fatsecret.com/platform-api): saved meals
- [Food Diary API](https://platform.fatsecret.com/platform-api): daily entries and monthly summaries
- [Exercise Diary API](https://platform.fatsecret.com/platform-api): daily exercise entries
- [Weight Tracking API](https://platform.fatsecret.com/platform-api): weight history

## Not published by fatsecret

- No first-party SDK in any package registry (community wrappers only, several abandoned)
- No first-party MCP server (community stdio servers only)
- No A2A agent card, no security.txt, no api-catalog
- No webhooks and no AsyncAPI — this API is request/response only
- No status page, no deprecation policy, no dated API changelog
- No trust center and no published certifications
